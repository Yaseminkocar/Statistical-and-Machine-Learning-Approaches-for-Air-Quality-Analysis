# Balıkesir Air Quality Data Mining

This project analyzes air quality measurements collected from a public transportation hub in Balıkesir, Turkey. The dataset includes particulate matter, gas pollutants, and meteorological variables, and it is used for exploratory analysis, preprocessing, classification, regression, clustering, and association rule mining tasks.

## Project Overview

The main goal of this project is to assess air quality patterns and build baseline predictive models using environmental sensor data. The analysis focuses especially on particulate matter values such as PM1, PM2.5, and PM10.

## Dataset

The dataset contains 2404 time-stamped records collected between 2025-09-01 and 2025-09-09. It includes:

- PM1, PM2.5, PM10
- CO, CO2, CH2O, O3, NO2, VOC
- Temperature
- Humidity
- Apparent temperature
- Timestamp-based features

## Methods Used

- Data cleaning and preprocessing
- Missing value analysis
- Outlier detection
- Feature selection
- Discretization
- Normalization and standardization
- PCA
- Classification
- Regression
- Clustering
- Association rule mining
